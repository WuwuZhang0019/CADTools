## 版本信息

- 方案状态：可执行分阶段方案
- 本地插件当前版本：

  - `Zyf.autoCAD/ZYF.autoCAD.csproj`：`AssemblyVersion`、`FileVersion` 为 `1.1.0.0`，`InformationalVersion` 为 `1.1.0`
- 插件项目位置：`G:\rust\CADTools`
- 插件主项目：`G:\rust\CADTools\Zyf.autoCAD\ZYF.autoCAD.csproj`
- 插件初始化入口：`G:\rust\CADTools\Zyf.autoCAD\App.cs`
- 插件命令入口：`G:\rust\CADTools\Zyf.autoCAD\MyCommand.cs`

- CAD工具页面：`G:\rust\PDSD-website\src\app\simple\cad-tools\page.tsx`
- 当前下载目录：`G:\rust\PDSD-website\src\public\downloads\cad-tools`
- 目标框架：`.NET Framework 4.7` / `net47`

## 1.1.0 更新目标

1. 增加自动下载、检查新版本功能。
2. 增加“关于”入口，展示官网网址、版权信息、版本号和运行环境信息。

## 总体实施原则

自动更新不直接依赖安装包文件名，而是由网站提供固定地址的版本清单文件。CAD 插件启动后在后台读取线上清单，将线上 `latestVersion` 与本地 `InformationalVersion` 比较。如果线上版本更高，再由用户确认是否下载和安装。

第一阶段先实现“发现新版本并引导用户下载”，第二阶段再实现“自动下载安装包并启动安装器”。这样可以降低 AutoCAD 插件 DLL 被占用、权限不足、下载失败、安装包损坏等风险。

所有自动检查失败必须静默处理，不影响 AutoCAD 启动和绘图流程；所有手动检查失败必须给出明确提示和官网入口。

## 最终交付范围

- 网站侧：
  - 固定地址版本清单 `zyf-cad-toolkit.latest.json`
  - CAD工具页面从同一份清单读取或同步展示最新版本、更新内容、下载地址
  - 发布包和 `sha256` 校验值
- 插件侧：
  - “检查更新”命令和菜单项
  - “关于”命令和菜单项
  - 启动后异步自动检查更新
  - 本地检查频率缓存和跳过版本缓存
  - 下载、校验并提权启动安装器
- 安装器侧：
  - 管理员权限安装到 `C:\ProgramData\Autodesk\ApplicationPlugins\ZYF.bundle`
  - 安装前处理 `acad.exe` 和 `09 CAD开图自动选字体.exe` 占用冲突
  - 支持卸载和覆盖安装

## 阶段 1：网站版本清单与下载页

### 目标

先让线上具备稳定的版本发现能力。客户端只依赖固定 URL 读取版本信息，不依赖页面 HTML 或安装包文件名。

### 新增文件

```text
G:\rust\PDSD-website\src\public\downloads\cad-tools\zyf-cad-toolkit.latest.json
```

上线后固定访问地址：

```text
https://www.nextoken.top/downloads/cad-tools/zyf-cad-toolkit.latest.json
```

### 推荐 JSON 结构

```json
{
  "appId": "zyf-cad-toolkit",
  "latestVersion": "1.1.0",
  "releaseDate": "2026-06-09",
  "title": "张裕锋工具集 1.1.0",
  "changelog": [
    "增加自动下载、检查新版本功能",
    "添加关于选项，显示网址、版权所有和版本信息"
  ],
  "downloadUrl": "https://www.nextoken.top/downloads/cad-tools/releases/zyf-cad-toolkit-1.1.0.exe",
  "sha256": "",
  "mandatory": false,
  "minimumSupportedVersion": "1.0.0",
  "homepageUrl": "https://www.nextoken.top/simple/cad-tools",
  "releaseNotesUrl": "https://www.nextoken.top/simple/cad-tools"
}
```

### 字段规则

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| `appId` | 是 | 固定为 `zyf-cad-toolkit`，客户端必须校验 |
| `latestVersion` | 是 | 使用语义化版本，例如 `1.1.0` |
| `releaseDate` | 是 | 使用 `yyyy-MM-dd` |
| `title` | 是 | 用于弹窗标题 |
| `changelog` | 是 | 用于更新弹窗展示 |
| `downloadUrl` | 是 | 使用完整 `https://` 绝对地址 |
| `sha256` | 阶段 3 后必填 | 安装包 SHA-256，小写十六进制 |
| `mandatory` | 是 | `true` 表示强制更新 |
| `minimumSupportedVersion` | 否 | 低于此版本时可强制更新 |
| `homepageUrl` | 是 | 关于窗口和失败提示使用 |
| `releaseNotesUrl` | 否 | 完整更新日志页面 |

### 执行任务

1. 在网站下载目录新增 `zyf-cad-toolkit.latest.json`。
2. 在 `releases` 子目录放置安装包：
   - `G:\rust\PDSD-website\src\public\downloads\cad-tools\releases\zyf-cad-toolkit-1.1.0.exe`
3. 计算安装包 `sha256` 并写入清单。
4. 更新 `page.tsx`：
   - 展示最新版本号
   - 展示发布日期
   - 展示更新内容
   - 下载按钮指向 `downloadUrl`
5. 如果网站页面暂时不能运行时读取 JSON，短期可以手动同步页面内容，但发布检查清单必须要求页面和 JSON 同步。

### 验收标准

- 浏览器能访问 `https://www.nextoken.top/downloads/cad-tools/zyf-cad-toolkit.latest.json`。
- JSON 格式合法，字段完整。
- `downloadUrl` 可直接下载。
- `sha256` 与实际安装包一致。
- CAD 工具页面展示的版本与 JSON 中 `latestVersion` 一致。

### 回滚方式

- 如果新清单有误，立即恢复上一版 `zyf-cad-toolkit.latest.json`。
- 如果安装包有误，先下线 `downloadUrl` 指向的文件，再恢复上一版清单。

## 阶段 2：插件侧基础更新检查

### 目标

先完成“发现新版并引导用户打开下载页”，不自动下载安装包。此阶段风险最低，可以优先发布。

### 建议新增代码结构

```text
Zyf.autoCAD\
  Services\
    UpdateManifest.cs
    UpdateCheckResult.cs
    UpdateService.cs
    UpdateSettings.cs
  UI\
    UpdatePromptForm.cs
    AboutForm.cs
```

如果暂时不想拆分目录，也可以先放在 `MyCommand.cs` 同级文件中，但不建议把网络请求、版本比较、弹窗逻辑全部塞进 `MyCommand.cs`。

### 本地配置位置

优先使用用户配置文件，避免注册表权限和清理问题：

```text
%APPDATA%\ZYFTools\config.json
```

推荐结构：

```json
{
  "lastCheckUpdateDate": "2026-06-09T10:00:00+08:00",
  "skippedVersion": "",
  "lastDownloadPath": ""
}
```

### 客户端检查流程

1. `App.Initialize()` 完成菜单创建和字体程序启动逻辑。
2. 订阅 `Application.Idle` 后只执行一次自动检查。
3. 自动检查先读取 `%APPDATA%\ZYFTools\config.json`。
4. 如果距离 `lastCheckUpdateDate` 不足 30 天，直接静默跳过。
5. 使用 `HttpClient` 异步请求版本清单，超时设置为 5 秒。
6. 自动检查所有异常都静默吞掉，只允许写 AutoCAD 命令行调试信息或本地日志。
7. 校验 `appId` 是否为 `zyf-cad-toolkit`。
8. 读取本地 `InformationalVersion`。
9. 使用 `System.Version` 比较版本号。
10. 如果线上版本更高，且不等于用户跳过的版本，则弹窗提示。
11. 用户点击“立即查看”时打开 `downloadUrl` 或 `homepageUrl`。
12. 用户点击“跳过此版本”时写入 `skippedVersion`。

### 命令与菜单

在 `MyCommand.cs` 新增命令：

```csharp
[CommandMethod(nameof(CheckUpdate), CommandFlags.Modal)]
public void CheckUpdate()
{
}

[CommandMethod(nameof(AboutZYFTools), CommandFlags.Modal)]
public void AboutZYFTools()
{
}
```

在 `App.cs` 新增菜单项：

```text
14 检查更新
15 关于
```

### 自动检查与手动检查差异

| 场景 | 频率限制 | 网络失败 | 已是最新版 | 发现新版 |
| --- | --- | --- | --- | --- |
| 自动检查 | 30 天 | 静默 | 静默 | 弹出更新提示 |
| 手动检查 | 不限制 | 明确提示 | 提示“当前已是最新版本” | 弹出更新提示 |

### 验收标准

- AutoCAD 启动速度不因网络请求明显变慢。
- 断网启动 AutoCAD 不弹错误窗口。
- 手动点击“检查更新”时能正确提示网络异常。
- 本地 `1.1.0` 遇到线上 `1.1.0` 提示已是最新版。
- 本地 `1.1.0` 遇到线上 `1.1.1` 弹出更新提示。
- 用户选择“跳过此版本”后，自动检查不再提示该版本。

### 回滚方式

- 保留菜单项时，可以临时关闭自动检查，只允许手动检查。
- 如网络逻辑影响启动，可注释 `Application.Idle` 中的自动检查调用，不影响原有 CAD 工具功能。

## 阶段 3：关于窗口

### 目标

提供用户可见的版本和支持信息，并作为手动检查更新的入口。

### 窗口内容

关于窗口使用 Windows Forms 或 WPF 均可。当前项目已启用：

```xml
<UseWPF>true</UseWPF>
<UseWindowsForms>true</UseWindowsForms>
```

建议优先使用 Windows Forms，部署依赖更轻，符合当前项目体量。

必须展示：

- 产品名称：张裕锋工具集
- 当前版本：读取 `InformationalVersion`
- 官网：`https://www.nextoken.top/simple/cad-tools`
- 作者或团队信息
- 版权所有信息
- “检查更新”按钮
- “打开官网”按钮

建议展示调试元数据：

- 当前 AutoCAD 版本
- 当前插件 DLL 实际加载路径
- 当前 .NET Framework 版本
- 当前系统用户名或计算机名可选，默认不展示，避免隐私争议

### 执行任务

1. 新增 `AboutForm`。
2. `AboutZYFTools` 命令打开 `AboutForm`。
3. `AboutForm` 中的“检查更新”按钮调用手动检查流程。
4. “打开官网”按钮使用 `Process.Start(homepageUrl)`。
5. 版本号统一从程序集读取，不在窗口中硬编码。

### 验收标准

- 菜单点击“关于”后窗口可正常打开。
- 窗口版本号与 `InformationalVersion` 一致。
- 点击“检查更新”能进入手动检查流程。
- 点击官网能打开浏览器。
- 没有网络时关于窗口仍能打开。

### 回滚方式

- 如窗口异常，只需从菜单中临时移除“关于”入口，不影响自动检查服务。

## 阶段 4：自动下载安装包与校验

### 目标

在阶段 2 已稳定的基础上，实现用户确认后自动下载安装包、校验 `sha256`、提示关闭 AutoCAD 并启动安装器。

### 下载策略

- 下载目录使用系统临时目录：

```csharp
Path.Combine(Path.GetTempPath(), "ZYFTools", "Downloads")
```

- 下载文件名从 `downloadUrl` 末尾获取，无法获取时使用：

```text
zyf-cad-toolkit-{latestVersion}.exe
```

- 下载前创建目录。
- 下载时使用异步流写入文件。
- 下载完成后计算 SHA-256。
- 如果清单中的 `sha256` 为空：
  - 测试环境允许继续，但弹出“无法校验安装包完整性”
  - 正式发布不允许为空

### 安装启动策略

下载校验通过后：

1. 提示用户保存图纸并关闭 AutoCAD。
2. 点击“开始安装”后使用管理员权限启动安装包：

```csharp
new ProcessStartInfo
{
    FileName = installerPath,
    UseShellExecute = true,
    Verb = "runas"
}
```

3. 插件不直接覆盖自身文件。
4. 插件不在 AutoCAD 进程内等待安装完成。

### 验收标准

- 用户确认后安装包能下载到 `%TEMP%\ZYFTools\Downloads`。
- 下载中断时给出清晰提示，不保留损坏文件或标记为 `.partial`。
- `sha256` 不匹配时阻止安装。
- 校验通过后能触发 UAC。
- 用户取消 UAC 时插件不崩溃，并提示安装已取消。

### 回滚方式

- 如果自动下载不稳定，保留“打开下载页”作为兜底按钮。
- 可以通过配置开关暂时禁用自动下载，只保留版本提示。

## 阶段 5：安装器与文件替换

### 目标

解决 AutoCAD 插件 DLL 和后台字体程序占用导致的覆盖失败问题，保证安装器能稳定替换 `ZYF.bundle`。

### 推荐安装器

使用 Inno Setup。安装器负责写入：

```text
C:\ProgramData\Autodesk\ApplicationPlugins\ZYF.bundle
```

建议安装器配置：

```ini
PrivilegesRequired=admin
DefaultDirName={commonappdata}\Autodesk\ApplicationPlugins\ZYF.bundle
DisableDirPage=yes
```

### 安装前处理

1. 检测 `acad.exe` 是否运行。
2. 如果 AutoCAD 正在运行，提示用户保存图纸并关闭 AutoCAD。
3. 强制结束后台程序：

```text
09 CAD开图自动选字体.exe
```

4. 等待进程退出，最多 5 秒。
5. 删除或覆盖旧版 `Contents` 文件。
6. 写入新版 `PackageContents.xml` 和 `Contents`。

### 卸载策略

1. 卸载前同样关闭 `09 CAD开图自动选字体.exe`。
2. 卸载路径统一为：

```text
C:\ProgramData\Autodesk\ApplicationPlugins\ZYF.bundle\unins000.exe
```

3. 如当前代码仍指向 `ZYF.bundle1`，应在本阶段修正。

### 验收标准

- 未运行 AutoCAD 时可直接覆盖安装。
- 正在运行 AutoCAD 时能提示关闭，不能静默失败。
- 正在运行 `09 CAD开图自动选字体.exe` 时安装器能关闭并覆盖。
- 安装完成后重新打开 AutoCAD 能加载新版菜单。
- `PackageContents.xml` 和 DLL 版本一致。
- “软件卸载”菜单能找到正确卸载程序。

### 回滚方式

- 保留上一版安装包。
- 如果新安装器失败，用户可手动删除 `C:\ProgramData\Autodesk\ApplicationPlugins\ZYF.bundle` 后安装上一版。

## 阶段 6：联调、发布与灰度

### 目标

确保网站、插件、安装器三部分在真实用户环境中闭环可用。

### 联调矩阵

| 测试项 | 环境 | 预期 |
| --- | --- | --- |
| 首次启动自动检查 | AutoCAD 2020 / 2021 / 2022 | 不阻塞启动 |
| 断网启动 | 无网络 | 不弹窗、不报错 |
| 手动检查断网 | 无网络 | 明确提示稍后重试 |
| 同版本检查 | 本地 `1.1.0` / 线上 `1.1.0` | 提示已是最新版 |
| 新版本检查 | 本地 `1.1.0` / 线上 `1.1.1` | 弹出更新提示 |
| 跳过版本 | 用户跳过 `1.1.1` | 自动检查不再提示 `1.1.1` |
| 强制更新 | `mandatory=true` | 不提供跳过选项 |
| 下载校验成功 | sha256 正确 | 可启动安装器 |
| 下载校验失败 | sha256 错误 | 阻止安装 |
| 覆盖安装 | 已安装旧版 | 安装后版本更新 |
| 卸载 | 已安装新版 | 卸载入口可用 |

### 发布步骤

1. 修改 `ZYF.autoCAD.csproj` 版本号。
2. 修改 `PackageContents.xml` 版本号。
3. 执行构建：

```powershell
dotnet build Zyf.autoCAD/ZYF.autoCAD.csproj -c Release
```

4. 制作安装包。
5. 在干净电脑或虚拟机安装测试。
6. 计算安装包 SHA-256：

```powershell
Get-FileHash "zyf-cad-toolkit-1.1.1.exe" -Algorithm SHA256
```

7. 上传安装包到：

```text
G:\rust\PDSD-website\src\public\downloads\cad-tools\releases
```

8. 更新 `zyf-cad-toolkit.latest.json`。
9. 更新 CAD 工具页面。
10. 部署网站。
11. 用浏览器验证 JSON 和安装包 URL。
12. 用旧版插件执行手动检查更新。
13. 用旧版插件执行自动检查更新。

- [ ] 断网自动检查无弹窗。
- [ ] 手动检查失败有提示。
- [ ] 覆盖安装可替换后台 EXE。
- [ ] 卸载入口路径正确。

### 灰度发布建议

第一版可以不做复杂灰度，只通过清单控制节奏：

1. 先上传安装包，但不更新 `latestVersion`。
2. 内部测试账号手动访问下载链接安装。
3. 测试通过后更新 `latestVersion`。
4. 如发现问题，立即恢复上一版 JSON。

后续可以扩展字段：

```json
{
  "rolloutPercent": 20,
  "blockedVersions": ["1.0.0"],
  "minimumSupportedVersion": "1.1.0"
}
```

## 实现细节建议

### 版本比较

使用 .NET 内置 `System.Version`：

```csharp
var localVersion = new Version(localVersionText);
var onlineVersion = new Version(manifest.LatestVersion);
if (onlineVersion > localVersion)
{
    // show update prompt
}
```

注意：`System.Version` 支持 `1.1.0`，也支持 `1.1.0.0`。客户端读取到 `1.1.0.0` 时可以直接比较。

### JSON 解析

目标框架为 `.NET Framework 4.7`。如果不想引入第三方依赖，可以添加引用：

```xml
<Reference Include="System.Web.Extensions" />
```

然后使用：

```csharp
System.Web.Script.Serialization.JavaScriptSerializer
```

如果后续项目已允许引入 NuGet，优先使用 `Newtonsoft.Json`，可读性和容错更好。

### HTTP 请求

- 复用静态 `HttpClient`。
- 设置 5 秒超时。
- 自动检查捕获所有异常并静默。
- 手动检查捕获异常后显示错误信息和官网地址。
- 请求 JSON 时禁用缓存可选：

```text
https://www.nextoken.top/downloads/cad-tools/zyf-cad-toolkit.latest.json?t=yyyyMMddHHmmss
```

手动检查建议带时间戳，自动检查不需要。

### 强制更新

当 `mandatory=true` 或本地版本低于 `minimumSupportedVersion` 时：

- 弹窗不显示“跳过此版本”。
- 可以显示“立即更新”“打开官网”“退出 AutoCAD”。
- 不建议在第一版直接禁用所有功能，避免误配置 JSON 导致用户无法工作。
- 若确需禁用，应只在严重兼容问题或安全问题时启用。

### 日志

建议写入：

```text
%APPDATA%\ZYFTools\logs\update.log
```

日志只记录：

- 检查时间
- 本地版本
- 线上版本
- 请求是否成功
- 下载是否成功
- 校验是否成功
- 安装器启动是否成功

不要记录图纸路径、用户名、项目名称等敏感信息。

## 风险与处理

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| AutoCAD 启动被网络拖慢 | 用户体验差 | 自动检查放在 `Application.Idle` 后异步执行 |
| 用户断网或代理拦截 | 自动检查失败 | 自动静默，手动提示 |
| DLL 被 AutoCAD 占用 | 覆盖失败 | 插件只启动安装器，安装器提示关闭 AutoCAD |
| 后台字体 EXE 占用 | 覆盖失败 | 安装器强制结束 `09 CAD开图自动选字体.exe` |
| JSON 配置错误 | 大量用户无法更新 | 客户端校验字段，网站保留上一版 JSON |
| sha256 为空或错误 | 安装包可信度不足 | 正式发布必须填写并校验 |
| 版本号来源不一致 | 检查结果错误 | 发布清单要求五处版本同步 |
| 官网页面和 JSON 不一致 | 用户困惑 | 发布检查清单强制同步 |
