## 递增、递减规则

专业前缀和数字保持原样，不限制为一个汉字或固定两、三位数字，不转换为整数，不丢失前导零。电、建、水、暖、结、电装、建装等使用相同规则。

| 当前图号 | THDZ 递增 | THDJ 递减 |
| --- | --- | --- |
| 电施-01 | 电变-01A | 保持电施-01 |
| 电装施-001 | 电装变-001A | 保持电装施-001 |
| 建装变-001A | 建装变-001B | 建装施-001 |
| 建装变-001a | 建装变-001b | 建装施-001 |
| 水变-0001Z | 水变-0001AA | 水变-0001Y |
| 水变-0001z | 水变-0001aa | 水变-0001y |
| 暖变-001AA | 暖变-001AB | 暖变-001Z |
| 暖变-001aa | 暖变-001ab | 暖变-001z |
| 结变-001BA | 结变-001BB | 结变-001AZ |
| 结变-001ba | 结变-001bb | 结变-001az |

按用户确认，已有后缀保留大小写：`Z → AA`、`z → aa`，递减时 `AA → Z`、`aa → z`。`A` 或 `a` 再递减时删除字母并把“变”还原成“施”；“施”图号再次递减时仅提示，不写入或刷新对象。

没有字母的“施”图号首次递增仍默认追加大写 A。小写 a 还原为“施”后不再携带原大小写信息，因此再次递增也按默认生成 A。

后缀须全为大写或全为小写，`Aa`、`aA` 等混用大小写的后缀给出格式提示。缺少数字、数字中夹字母、缺少连字符或文字末尾含额外说明等格式不处理。

## 对象与菜单接入

每次仅修改被选对象的 DXF 组码 1 文字。脚本接收 `TEXT`、`MTEXT`、`ATTRIB`；属性对象仍须能由现有 `entsel` 方式选中，没有新增块内嵌套选择。含组码 3 分段内容的多行文字、自定义天正对象和其他对象给出提示，不尝试写入。写入失败时显示提示，成功后刷新对象并显示修改前后的图号。

插件同时注册 `THDZ`、`THDJ` 两条 C# 入口。两者都从所属程序集的 Tools 目录加载同一个脚本，再显式调用指定方向，因此首次使用 `THDJ` 不要求先运行 `THDZ`。现有菜单仍执行递增。加载脚本本身不会自动进入选择，避免首次递减时误触发递增或重复选择。
