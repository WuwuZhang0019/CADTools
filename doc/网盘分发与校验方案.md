# CAD 工具网盘分发与校验方案

## 背景

当前线上网站部署在中国大陆服务器，并使用个人或非经营性备案主体。若网站公开托管并提供 `.exe` 安装包直接下载，可能被接入商、浏览器安全检测、备案审核或用户投诉流程识别为软件下载分发行为，从而增加备案项目不匹配、内容安全审核、软件下载合规解释等风险。

本方案将线上网站从“直接托管安装包”调整为“展示版本信息、校验信息和外部网盘下载入口”。安装包不放在网站服务器上，用户需要更新时跳转到百度网盘链接，自行下载后可按网站和客户端提供的 SHA-256 信息校验文件完整性。

本方案只用于降低风险，不构成法律意见，也不保证完全消除备案、内容安全或软件分发相关风险。正式上线前仍应结合备案主体、网站页面形态、接入商规则和实际业务性质判断。

## 依据与风险判断

- 《非经营性互联网信息服务备案管理办法》要求在中国境内提供非经营性互联网信息服务应依法履行备案手续，且网站应保证提供的信息内容合法；备案信息还应与实际服务项目保持一致。
- 政务服务事项中也将非经营性互联网信息服务备案作为通信管理部门管理事项。
- 国家网信办关于应用程序分发平台备案的公开说明表明，应用分发服务本身存在单独的监管关注点。虽然本项目是 CAD 插件安装包，不等同于移动 App 分发平台，但“公开托管可执行安装包并提供下载入口”的页面形态更容易被外部审核理解为软件下载分发。

## 调整目标

1. 网站服务器不再存放 `.exe` 安装包。
2. 网站页面不再提供本站 `.exe` 直链下载。
3. 版本清单继续保留版本号、发布日期、文件名、文件大小、SHA-256、更新内容和外部下载地址。
4. 插件客户端发现新版本后，只打开网盘链接或下载说明页，不在客户端内自动从本站下载安装包。
5. 用户自行从网盘下载后，可根据 SHA-256 校验安装包完整性。

## 推荐版本清单结构

固定清单仍保留：

```text
https://www.nextoken.top/downloads/cad-tools/zyf-cad-toolkit.latest.json
```

推荐 JSON：

```json
{
  "appId": "zyf-cad-toolkit",
  "latestVersion": "1.1.1",
  "releaseDate": "2026-06-10",
  "title": "张裕锋工具集 1.1.1",
  "changelog": [
    "检查更新改为网盘分发模式，网站不再托管安装包",
    "添加关于选项，显示官网、版权和版本信息",
    "安装器支持自定义安装路径"
  ],
  "distributionMode": "external",
  "fileName": "zyf-cad-toolkit-1.1.1.exe",
  "fileSize": 6494525,
  "downloadUrl": "https://pan.baidu.com/s/1R867-BFEmGrYfA4Y94oEpQ?pwd=3d7t",
  "downloadCode": "3d7t",
  "sha256": "106305380f05c9ca466a0fa0be9d1b15c5c024bfb43c5deca32169b809649fa0",
  "mandatory": false,
  "minimumSupportedVersion": "1.0.0",
  "homepageUrl": "https://www.nextoken.top/simple/cad-tools",
  "releaseNotesUrl": "https://www.nextoken.top/simple/cad-tools"
}
```

字段说明：

- `distributionMode`：`external` 表示外部网盘分发，客户端不得自动下载安装。
- `downloadUrl`：百度网盘分享链接，网站按钮和客户端更新提示均跳转此链接。
- `downloadCode`：百度网盘提取码；如果链接不需要提取码，可为空。
- `sha256`：安装包 SHA-256，用于用户端和网页展示校验。
- `fileName`：期望用户下载到的安装包名称。
- `fileSize`：安装包字节数，用于辅助用户确认文件是否一致。

## 网站侧改造

1. 删除线上仓库中的安装包文件：

```text
src/public/downloads/cad-tools/releases/zyf-cad-toolkit-1.1.0.exe
```

2. 保留版本清单：

```text
src/public/downloads/cad-tools/zyf-cad-toolkit.latest.json
```

3. CAD 工具页下载按钮改为：

- 文案建议：`网盘下载` 或 `获取安装包`
- 链接指向 `downloadUrl`
- 如有提取码，在按钮附近展示：`提取码：xxxx`
- 页面显示 SHA-256 和文件名，提醒用户下载后核对。

4. 页面避免使用强商业软件官网表达：

- 避免“立即购买”“会员”“企业版”“付费下载”“定价”等商业化内容与该工具页面强绑定。
- 页面定位建议保持为个人技术工具、学习交流、辅助工具说明。
- 如未来需要商业化分发，应重新评估备案、资质、软件著作权、用户协议和隐私政策等事项。

## 客户端侧改造

1. 更新检查仍读取固定 JSON 清单。
2. 当 `distributionMode` 为 `external` 时：

- 自动检查：只提示有新版本，不自动下载。
- 手动检查：弹窗展示版本、更新内容、文件名、SHA-256。
- 用户点击按钮时打开百度网盘链接。
- 不执行客户端内置下载、SHA-256 自动校验和 `runas` 自动启动安装器流程。

3. 保留 `sha256` 的用途：

- 客户端弹窗可展示校验值。
- 关于页面或下载说明页可提供 PowerShell 校验命令。

推荐校验命令：

```powershell
Get-FileHash "zyf-cad-toolkit-1.1.1.exe" -Algorithm SHA256
```

## 发布流程

1. 本地构建插件：

```powershell
dotnet build Zyf.autoCAD/ZYF.autoCAD.csproj -c Release
```

2. 编译安装器：

```powershell
& "D:\Inno Setup 6\ISCC.exe" "G:\rust\CADTools\installer\ZYFTools.iss"
```

3. 计算安装包 SHA-256：

```powershell
Get-FileHash "G:\rust\CADTools\dist\zyf-cad-toolkit-1.1.1.exe" -Algorithm SHA256
```

4. 将安装包上传到百度网盘。
5. 更新 `zyf-cad-toolkit.latest.json`：

- `distributionMode`
- `downloadUrl`
- `downloadCode`
- `fileName`
- `fileSize`
- `sha256`

6. 删除网站仓库中的 `.exe` 安装包文件。
7. 部署网站。
8. 用浏览器验证页面不再从本站下载 `.exe`。
9. 用旧版插件验证更新提示会打开网盘链接。

## 验收标准

- 网站构建产物中不包含 `.exe` 安装包。
- CAD 工具页按钮跳转百度网盘，不访问本站 `.exe` 地址。
- 版本清单 JSON 可访问，且保留 SHA-256、文件名和外部下载地址。
- 客户端发现更新时打开网盘链接，不自动下载本站安装包。
- 页面明确展示 SHA-256 校验信息。

## 回滚方式

如网盘链接失效：

1. 更新 `zyf-cad-toolkit.latest.json` 的 `downloadUrl` 和 `downloadCode`。
2. 不需要重新发布客户端。
3. 如果安装包内容未变，`sha256` 不变；如果重新上传了不同文件，必须重新计算并更新 `sha256`。
