# 张裕锋工具集 - 更新机制与“关于”功能设计方案 (已优化版)

本方案设计了用户端软件的检测更新机制，由原先的“定期强制/自动弹框检测”转为“启动静默检测 + 业务命令低打扰提醒 + 关于页手动更新”的机制。

---

## 1. 核心业务流程与设计

为了给用户提供无打扰的高效绘图环境，更新机制的整体流向设计如下：

### 1.1 启动阶段：无感检测与缓存统一维护
- **行为**：AutoCAD 启动并进入闲置状态（`Application.Idle`）时，插件在后台异步且静默地请求服务器获取最新版本信息。
- **机制**：
  - **取消启动弹窗**：完全取消启动时的自动安装提示弹窗（不再在 `OnApplicationIdle` 中调用 `ShowAutomaticResult`）。
  - **取消频率限制**：自动静默检查将不再受“30天检测一次”的限制，每次启动均会发出一次轻量请求，确保本地缓存的时效性。
  - **统一维护缓存**：静默检测与手动检测结果统一在 `UpdateService.CheckForUpdatesAsync` 内部维护，成功或失败都会自动更新全局静态变量 `UpdateService.CachedResult`。

### 1.2 使用阶段：精准、极简的命令提醒
- **防干扰机制**：
  - **精确定位命令**：命令提醒**仅在用户主动触发的核心业务命令**入口执行（如 `JSSS`、`MEE`、`DTCL`、`THDZ`、`QHK`、`MAA`、`P0`、`FAS`、`PTB`、`DXGS`）。
  - **跳过辅助与自动命令**：启动时自动发送的 `FSN_LOAD` 命​​令、以及 `CheckUpdate`、`AboutZYFTools`、`UninstallSoftware`、`StartFontApp` 和 `ResetFontApp` 等辅助/配置类命令，将**不会**注入提醒逻辑，避免启动阶段间接弹出提示。
  - **会话防打扰**：每个 CAD 运行会话（Session）中，即使检测到新版本，命令触发的弹窗**只会提示一次**。用户点击“知道了”后，当前 CAD 会话内后续执行任何命令都不会再重复弹窗。
  - **极简弹窗文案**：弹窗不再罗列复杂的版本日志与发布时间，只显示极其精简的提醒，防止打断用户画图心流：
    > “检测到新版本可用，您可以在空闲时前往菜单栏的【关于】面板进行检查更新与升级。”

### 1.3 关于面板：完整展示与刷新机制
- **信息展示**：关于面板（`AboutForm`）中新增两行内容，清晰展示：
  - “最新版本：X.Y.Z”（若缓存未就绪或获取失败，显示友好占位提示）
  - “发布时间：YYYY-MM-DD”
- **手动检查刷新**：用户在关于面板中点击【检查更新】时，点击事件不仅执行原有的手动更新逻辑，还会重新更新 `UpdateService.CachedResult`，并实时刷新关于面板上展示的“最新版本”与“发布时间”文本。

### 1.4 版本跳过 (SkippedVersion) 策略
- **静默检测**：启动静默检测时，如果发现最新版本是用户已选择“跳过”的版本（`SkippedVersion`），`CheckForUpdatesAsync` 会将状态标记为 `VersionSkipped`。此时其 `HasUpdate` 属性为 `false`，**不会触发业务命令里的更新提醒弹窗**。
- **手动检测**：用户在关于面板中手动点击“检查更新”时，**不受跳过策略影响**，依然可以正常发现该版本并引导升级。

## 2. 详细技术实现设计

### 2.1 状态存储与提醒控制 (`UpdateService.cs`)
在 `UpdateService` 中添加全局静态变量、重构检测方法，并添加极简的命令触发逻辑：

```csharp
// 全局缓存的检测结果
public static UpdateCheckResult CachedResult { get; private set; }

// 本会话是否已进行过更新提醒的标志位
private static bool _hasNotifiedThisSession = false;

/// <summary>
/// 当用户运行命令时调用的提醒逻辑
/// </summary>
public static void CheckAndNotifyUpdateOnCommandRun()
{
    // 如果本会话已经提醒过，直接跳过，避免重复干扰
    if (_hasNotifiedThisSession) return;

    // 只有当有可用更新，且非跳过版本时，才进行弹窗提醒
    if (CachedResult != null && CachedResult.HasUpdate)
    {
        _hasNotifiedThisSession = true;
        
        MessageBox.Show(
            "检测到新版本可用，您可以在空闲时前往菜单栏的【关于】面板进行检查更新与升级。",
            "更新提醒",
            MessageBoxButtons.OK,
            MessageBoxIcon.Information);
    }
}
```

修改 `CheckForUpdatesAsync` 核心逻辑，统一维护 `CachedResult`，并解除自动检测的 30 天频率限制：

```csharp
public static async Task<UpdateCheckResult> CheckForUpdatesAsync(bool isManual)
{
    var settings = UpdateSettings.Load();
    string localVersion = GetLocalVersion();

    // 只有在手动检查时才受 30 天限制影响（或者完全移除静默频率检查，只让手动检查无限制）
    // 方案调整为：自动检测（!isManual）不走 30 天频率限制，直接去获取最新清单以缓存；手动检测也无限制。
    // 即直接取消 30 天的检查跳过逻辑。
    
    UpdateCheckResult result;
    try
    {
        string url = isManual ? $"{ManifestUrl}?t={DateTime.Now:yyyyMMddHHmmss}" : ManifestUrl;
        string json = await HttpClient.GetStringAsync(url).ConfigureAwait(false);
        UpdateManifest manifest = ParseManifest(json);

        settings.LastCheckUpdateDate = DateTimeOffset.Now;
        settings.Save();

        if (!IsManifestValid(manifest))
        {
            result = new UpdateCheckResult
            {
                Status = UpdateCheckStatus.InvalidManifest,
                LocalVersion = localVersion,
                Manifest = manifest,
                Message = "版本清单格式不完整或 appId 不匹配。"
            };
        }
        else
        {
            Version local = ParseVersion(localVersion);
            Version online = ParseVersion(manifest.LatestVersion);
            bool isForced = IsForcedUpdate(local, manifest);

            if (online <= local)
            {
                result = new UpdateCheckResult
                {
                    Status = UpdateCheckStatus.Latest,
                    LocalVersion = localVersion,
                    Manifest = manifest,
                    Message = "当前已是最新版本。"
                };
            }
            // 自动静默检测且不是强制更新时，如果匹配到了用户跳过的版本，则标记为已跳过，后续命令将不再提醒
            else if (!isManual && !isForced && string.Equals(settings.SkippedVersion, manifest.LatestVersion, StringComparison.OrdinalIgnoreCase))
            {
                result = new UpdateCheckResult
                {
                    Status = UpdateCheckStatus.VersionSkipped,
                    LocalVersion = localVersion,
                    Manifest = manifest,
                    Message = "已跳过此版本。"
                };
            }
            else
            {
                result = new UpdateCheckResult
                {
                    Status = UpdateCheckStatus.UpdateAvailable,
                    LocalVersion = localVersion,
                    Manifest = manifest,
                    IsForced = isForced,
                    Message = $"发现新版本 {manifest.LatestVersion}。"
                };
            }
        }
    }
    catch (Exception ex)
    {
        result = new UpdateCheckResult
        {
            Status = UpdateCheckStatus.Failed,
            LocalVersion = localVersion,
            Message = "检查更新失败，请稍后重试。"
        };
    }

    // 统一在这里更新缓存
    CachedResult = result;
    return result;
}
```

### 2.2 启动无感检测 (`App.cs`)
调整 `OnApplicationIdle` 的逻辑，不再在后台检测到更新时直接强行弹窗：

```csharp
private async void OnApplicationIdle(object sender, EventArgs e)
{            
    Application.Idle -= OnApplicationIdle;
    StartFontAppIfNotRunning();
    
    // 静默在后台进行更新检测，检测结果会自动更新到 UpdateService.CachedResult 中
    await UpdateService.CheckForUpdatesAsync(isManual: false);
}
```

### 2.4 “关于”面板界面升级与手动检查 (`AboutForm.cs`)
升级 `AboutForm` 以支持显示最新版本和发布时间，并展示缓存的信息。

```csharp
private static string BuildSummaryText()
{
    string acadVersion = ReadAutoCadVersion();
    Assembly assembly = typeof(AboutForm).Assembly;
    
    string latestVersionStr = "最新版本：点击【检查更新】获取";
    string releaseDateStr = "发布时间：--";
    
    var cached = UpdateService.CachedResult;
    if (cached != null)
    {
        if (cached.Status == UpdateCheckStatus.Failed)
        {
            latestVersionStr = "最新版本：获取失败";
        }
        else if (cached.Status == UpdateCheckStatus.Latest)
        {
            latestVersionStr = "最新版本：已是最新版本";
        }
        else if (cached.Manifest != null)
        {
            latestVersionStr = $"最新版本：{cached.Manifest.LatestVersion}";
            if (!string.IsNullOrWhiteSpace(cached.Manifest.ReleaseDate))
            {
                releaseDateStr = $"发布时间：{cached.Manifest.ReleaseDate}";
            }
        }
    }

    return string.Join(Environment.NewLine, new[]
    {
        $"当前版本：{UpdateService.GetLocalVersion()}",
        latestVersionStr,
        releaseDateStr,
        $"官网：{UpdateService.HomepageUrl}",
        "作者：张裕锋",
        "版权所有 © 张裕锋",
        string.Empty,
        $"AutoCAD 版本：{acadVersion}",
        $"插件加载路径：{assembly.Location}",
        $".NET 运行时版本：{Environment.Version}"
    });
}
```

手动检查事件完成后，同时更新缓存并刷新表单文本：

```csharp
checkButton.Click += (sender, args) =>
{
    Cursor oldCursor = Cursor.Current;
    try
    {
        Cursor.Current = Cursors.WaitCursor;
        // 手动检查更新，方法内部会更新 CachedResult
        UpdateCheckResult result = UpdateService.CheckForUpdatesAsync(isManual: true).GetAwaiter().GetResult();
        
        // 刷新 UI 上显示的最新版本和发布时间
        summary.Text = BuildSummaryText();
        
        // 弹出手动更新向导
        UpdateService.ShowManualResult(result);
    }
    finally
    {
        Cursor.Current = oldCursor;
    }
};
```
