# 张裕锋工具集 - 更新机制与“关于”功能设计方案 (已优化版)

本方案设计了用户端软件的检测更新机制，由原先的“定期强制/自动弹框检测”转为“启动静默检测 + 业务命令低打扰提醒 + 关于页手动更新”的机制。

---

## 1. 核心业务流程与设计

为了给用户提供无打扰的高效绘图环境，更新机制的整体流向设计如下：

### 1.1 启动阶段：无感检测与缓存统一维护
- **行为**：AutoCAD 启动并进入闲置状态（`Application.Idle`）时，插件在后台异步且静默地请求服务器获取最新版本信息。
- **机制**：
  - **取消启动弹窗**：完全取消启动时的自动安装提示弹窗（不再在 `OnApplicationIdle` 中调用 `ShowAutomaticResult`，并将该废弃方法从代码库中清理，避免日后误用）。
  - **取消频率限制**：自动静默检查将不再受“30天检测一次”的限制，每次启动均会发出一次轻量请求，确保本地缓存的时效性。
  - **统一维护缓存**：静默检测与手动检测结果统一在 `UpdateService.CheckForUpdatesAsync` 内部维护，成功或失败都会自动更新全局静态变量 `UpdateService.CachedResult`。

### 1.2 使用阶段：精准、极简的命令提醒
- **防干扰机制**：
  - **精确定位业务命令**：命令提醒**仅在用户主动触发的核心业务命令**入口执行。包括：
    - `JSSS`（急速瘦身）
    - `MEE`（布置疏散指示）
    - `DTCL`（底图处理）
    - `THDZ`（图号文字递增）
    - `QHK`（图片去黑框）
    - `MAA`（文字复制）
    - `P0`（0层置为当前图层）
    - `FAS`（消防回路统计）
    - `PTB`（PL线转桥架）
    - `DXGS`（自动标导线根数）
  - **跳过辅助、配置与自动命令**：以下命令被归类为辅助或配置类命令，**不会**触发提醒：
    - 自动/后台命令：`FSN_LOAD`
    - 更新/关于命令：`CheckUpdate`、`AboutZYFTools`
    - 辅助/设置/卸载命令：`UninstallSoftware`、`StartFontApp`、`ResetFontApp`、`DXGSSETUP`（标根数设置）、`DXGSCFG`（标根数配置）
  - **会话防打扰**：每个 CAD 运行会话（Session）中，即使检测到新版本，命令触发的弹窗**只会提示一次**。用户点击“知道了”后，当前 CAD 会话内后续执行任何命令都不会再重复弹窗。
  - **极简弹窗文案**：弹窗不再罗列复杂的版本日志与发布时间，只显示极其精简的提醒，防止打断用户画图心流：
    > “检测到新版本可用，您可以在空闲时前往菜单栏的【关于】面板进行检查更新与升级。”

### 1.3 关于面板：完整展示与刷新机制
- **信息展示**：关于面板（`AboutForm`）中新增两行内容，清晰展示：
  - “最新版本：X.Y.Z”（若缓存未就绪或获取失败，显示友好占位提示）
  - “发布时间：YYYY-MM-DD”
- **手动检查刷新**：用户在关于面板中点击【检查更新】时，点击事件不仅执行原有的手动更新逻辑，还会重新更新 `UpdateService.CachedResult`，并实时刷新关于面板上展示的“最新版本”与“发布时间”文本。

### 1.4 版本跳过 (SkippedVersion) 策略
- **静默检测**：启动静默检测时，如果发现最新版本是用户已选择“跳过”的版本（`SkippedVersion`），`CheckForUpdatesAsync` 会将状态标记为 `VersionSkipped`。此时其 `HasUpdate` 属性为 `false`，**不会触发业务命令里的更新提醒弹窗**。
- **手动检测**：用户在关于面板中手动点击“检查更新”时，**不受跳过策略影响**，依然可以正常发现该版本并引导升级。

## 2. 详细技术实现设计

### 2.1 状态存储与提醒控制 (`UpdateService.cs`)
在 `UpdateService` 中添加全局静态变量、重构检测方法，并添加极简的命令触发逻辑：

```csharp
// 全局缓存的检测结果
public static UpdateCheckResult CachedResult { get; private set; }

// 本会话是否已进行过更新提醒的标志位
private static bool _hasNotifiedThisSession = false;

/// <summary>
/// 当用户运行命令时调用的提醒逻辑
/// </summary>
public static void CheckAndNotifyUpdateOnCommandRun()
{
    // 如果本会话已经提醒过，直接跳过，避免重复干扰
    if (_hasNotifiedThisSession) return;

    // 只有当有可用更新，且非跳过版本时，才进行弹窗提醒
    if (CachedResult != null && CachedResult.HasUpdate)
    {
        _hasNotifiedThisSession = true;
        
        MessageBox.Show(
            "检测到新版本可用，您可以在空闲时前往菜单栏的【关于】面板进行检查更新与升级。",
            "更新提醒",
            MessageBoxButtons.OK,
            MessageBoxIcon.Information);
    }
}
```

### 2.2 废弃接口清理
- **ShowAutomaticResult(UpdateCheckResult)**：该方法原本用于启动时弹出下载对话框。为了彻底根除日后误用导致启动弹窗的问题，该方法已从代码中**彻底清理删除**。

### 2.3 字段兼容性说明
为了保持数据模型的可读性与未来的重构便利，对旧逻辑遗留字段做如下处理：
- **`LastCheckUpdateDate`**：该字段依然保留并正常在每次检测成功后写入配置文件中。其作用保留为：(1) 作为更新日志的最后检测时间戳；(2) 兼容旧版本可能升级上来的配置数据。**在当前代码中已不用于进行 30 天频率拦截**。
- **`UpdateCheckStatus.FrequencySkipped`**：此枚举值在自动检测机制取消 30 天限制后，在当前版本的检测流程中已不再产生。此值目前作为历史兼容保留在枚举中，后续版本重构时可安全将其删除。

## 3. 拟修改与实现文件

### 3.1 核心命令注入 (`MyCommand.cs`)
**仅在业务命令**中执行拦截（DXGS 专门提取到对应的命令方法中以绕开配置命令 `DXGSSETUP` 和 `DXGSCFG`）：

```csharp
[CommandMethod(nameof(JSSS), CommandFlags.Modal)]
public void JSSS()
{
    UpdateService.CheckAndNotifyUpdateOnCommandRun();
    // ...
}

[CommandMethod(nameof(DXGS), CommandFlags.Modal)]
public void DXGS()
{
    UpdateService.CheckAndNotifyUpdateOnCommandRun();
    RunDxgsLispCommand(nameof(DXGS));
}

// 辅助配置类命令不添加任何 CheckAndNotifyUpdateOnCommandRun 调用，保持干净
[CommandMethod(nameof(DXGSSETUP), CommandFlags.Modal)]
public void DXGSSETUP()
{
    RunDxgsLispCommand(nameof(DXGSSETUP));
}
```

## 4. 最小化验收清单 (Acceptance Checklist)

为了保证本次重构的功能正确，建议通过以下清单进行验收测试：

1. **CAD 启动静默验收**：
   - 启动 AutoCAD，进入绘图区。
   - 确认没有弹出任何有关插件升级的提示框、下载框，保持完全静默。
2. **业务命令提醒一次性验收**：
   - 模拟检测到新版本（将本地版本号改小，或将服务器清单上的版本号改大）。
   - 输入并运行任意核心业务命令（如 `JSSS`）。
   - 确认弹出极简的更新提醒窗口：“**检测到新版本可用，您可以在空闲时前往菜单栏的【关于】面板进行检查更新与升级。**”，且点击“知道了”即可关闭。
   - 再次输入并运行任意命令（如 `MEE` 或 `DXGS`），确认**不再弹出**该更新提示框，整个 CAD 会话中最多提醒一次。
3. **辅助/配置命令过滤验收**：
   - 模拟检测到新版本。
   - 在未触发过弹窗的情况下，运行 `DXGSSETUP` 或 `DXGSCFG` 等设置/配置命令，确认**不触发**更新弹窗。
   - 确认后台开图时自动发送的 `FSN_LOAD` 命令**不触发**更新弹窗。
4. **版本跳过策略验收**：
   - 模拟检测到新版本，在手动更新界面选择“跳过此版本”。
   - 重启 AutoCAD。再次运行任何业务命令（如 `JSSS`），确认**不会弹出**更新提醒。
   - 打开“关于”面板，点击【检查更新】按钮，确认**依然能检测到**最新版本并弹出更新选项，手动检测不受跳过版本限制。
5. **关于面板与数据刷新验收**：
   - 打开“关于”面板，展示的文本应正确包含当前的最新版本和发布时间（根据启动时静默检测的结果）。
   - 在关于面板中点击【检查更新】，在检测完毕并弹出向导后，关闭向导，关于面板中展示的最新版本与发布时间应根据最新结果进行**实时刷新**。
6. **弱网/无网容错验收**：
   - 模拟网络断开或服务器访问失败的情况。
   - 启动 AutoCAD 后运行业务命令，确认命令正常执行，**不弹出**任何网络失败的报错窗口或更新提醒。
   - 打开“关于”面板，面板上的最新版本显示为“最新版本：获取失败”，点击【检查更新】后提示网络失败。
