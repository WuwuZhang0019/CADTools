# CAD工具自定义安装路径方案 (NTFS 目录联接法)

本方案旨在解决 CAD 插件（`.bundle` 自动加载机制）默认必须安装在系统硬编码路径（如 `C:\ProgramData\Autodesk\ApplicationPlugins`）的问题，允许用户在安装时自定义安装路径（如安装至 D 盘），同时确保 AutoCAD 能够正常识别并加载插件，且无需修改任何 C# 插件代码。

## 实施状态

- 已在 `installer/ZYFTools.iss` 中实现自定义安装路径。
- 安装器默认安装到 `{autopf}\ZYFTools`，安装时允许用户选择其他目录。
- 插件文件实际释放到 `{app}\ZYF.bundle`。
- 安装完成后创建 `C:\ProgramData\Autodesk\ApplicationPlugins\ZYF.bundle` 目录联接，指向 `{app}\ZYF.bundle`。
- 卸载前会删除标准路径下的目录联接，并删除 `{app}\ZYF.bundle` 下的实际安装文件。

---

## 1. 原理解析与优势

### 1.1 NTFS 目录联接 (Directory Junction)
Windows 文件系统支持 NTFS 目录联接。通过 `mklink /j` 命令，可以在标准加载路径下创建一个“虚拟文件夹”，将其指向用户自定义的物理路径。

*   **AutoCAD 的视角**：当 AutoCAD 扫描 `C:\ProgramData\Autodesk\ApplicationPlugins\ZYF.bundle` 时，文件系统会无缝重定向。对于 AutoCAD 来说，它认为文件就在 C 盘默认位置，从而顺利读取 `PackageContents.xml` 并加载 DLL。
*   **客户端代码的视角**：C# 插件内部、Lisp 文件和自定义 CUIX 菜单中使用的所有相对路径（如 `./Contents/Tools/...`）无需做任何修改，系统会自动完成路径映射。
*   **磁盘空间的视角**：插件的核心大文件（DLL、VLX、Lisp、字体 EXE 等）全部物理存储在用户指定的自定义磁盘分区中，不占用 C 盘空间。

### 1.2 方案优势
1.  **零代码修改**：客户端 C# 逻辑和 `PackageContents.xml` 配置文件完全不需改动。
2.  **避免版本绑定**：无需像注册表方案那样针对 AutoCAD 2020、2024 等每个具体版本去分别写注册表，一处联接，所有 AutoCAD 版本自动通用。
3.  **支持绿色卸载**：卸载时只需断开联接并删除自定义目录，不留系统垃圾。

## 2. 具体实现步骤

### 2.1 安装阶段 (Installation)
1.  **用户选择路径**：用户在安装界面选择自定义路径（假设用户选择 `D:\Softwares\ZYFTools`）。
2.  **释放文件**：安装器将整个插件包解压释放到该自定义路径下，目录结构如：
    ```text
    D:\Softwares\ZYFTools\ZYF.bundle\PackageContents.xml
    D:\Softwares\ZYFTools\ZYF.bundle\Contents\...
    ```
3.  **创建联接**：安装程序在释放文件完成后，调用系统命令行执行以下命令：
    ```cmd
    mklink /j "C:\ProgramData\Autodesk\ApplicationPlugins\ZYF.bundle" "D:\Softwares\ZYFTools\ZYF.bundle"
    ```
    *(注：如果目标 `ApplicationPlugins` 目录不存在，安装器应先创建该目录)*

### 2.2 卸载阶段 (Uninstallation)
1.  **断开联接**：卸载程序启动后，先删除标准路径下的目录联接。
    ```cmd
    rmdir "C:\ProgramData\Autodesk\ApplicationPlugins\ZYF.bundle"
    ```
    *安全提示：在 Windows 中，使用 `rmdir` 命令删除目录联接只会切断链接本身，**绝对不会**删除自定义路径 `D:\Softwares\ZYFTools\ZYF.bundle` 里的物理文件。*
2.  **删除物理文件**：卸载程序将自定义路径 `D:\Softwares\ZYFTools` 下的全部文件安全删除。

## 3. 安装器配置示例 (以 Inno Setup 为例)

如果使用 Inno Setup 打包，可以在 `.iss` 脚本中进行如下配置：

```pascal
[Setup]
AppName=张裕锋工具集
AppVersion=1.1.0
DefaultDirName={autopf}\ZYFTools
; 必须要求管理员权限，因为创建目录联接和写入 ProgramData 都需要权限
PrivilegesRequired=admin

[Files]
; 将编译好的文件打包至用户选择的自定义安装路径 {app} 下
Source: "G:\rust\CADTools\Zyf.autoCAD\bin\Release\*"; DestDir: "{app}\ZYF.bundle"; Flags: recursesubdirs createallsubdirs

[Run]
; 安装完成后，在系统标准路径下创建目录联接指向用户自定义的 {app}
Filename: "{cmd}"; Parameters: "/c mklink /j ""C:\ProgramData\Autodesk\ApplicationPlugins\ZYF.bundle"" ""{app}\ZYF.bundle"""; Flags: runhidden

[UninstallRun]
; 卸载前，先安全删除标准路径下的目录联接
Filename: "{cmd}"; Parameters: "/c rmdir ""C:\ProgramData\Autodesk\ApplicationPlugins\ZYF.bundle"""; Flags: runhidden
```

---

## 4. 注意事项

1.  **权限要求**：创建和删除联接需要管理员权限。因此，安装程序（`.exe`）必须要求以管理员身份运行（即触发系统的 UAC 提权提示）。
2.  **清理残留**：若用户之前手动安装过旧版插件，或残留了真实的 `C:\ProgramData\Autodesk\ApplicationPlugins\ZYF.bundle` 物理文件夹，安装程序在执行 `mklink /j` 之前必须先检测并清空/删除该同名物理文件夹，否则联接创建会失败。
3.  **多用户支持**：`C:\ProgramData` 下的联接对该电脑上的所有 Windows 账户生效。如果仅针对当前用户，可将联接建立在：
    `%APPDATA%\Autodesk\ApplicationPlugins\ZYF.bundle`
