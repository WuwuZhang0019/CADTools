## 使用入口和原命令

选择“张裕锋工具集 → 14 应急照明”，或者输入 `EmergencyLighting`。入口在当前图纸按需加载模块并打开 `ELSTAT` 回路统计流程，“关于”顺延为第 15 项。每张新图纸首次使用时也通过此入口加载。

加载后可直接使用上游全部命令，包括：

| 功能 | 命令 |
| --- | --- |
| 回路统计及结果保存 | `ELSTAT`、`ELPOWER`、`ELISSUES`、`ELSAVERESULT`、`ELSAVELIB` |
| 设备库和参数 | `ELDEVLIB`、`ELSETUP`、`ELSAMPLE`、`ELJBOX`、`ELPRESET`、`ELDEVPICK` |
| 系统图和回路追加 | `ELGEN`、`ELDIAG`、`ELTEMPLATE`、`CCKK`、`CCKK1`、`CCKK2` |
| 连通和引线处理 | `ELGAPTEST`、`ELTRACE`、`ELPAIRGAP`、`ELPAIRLEADER`、`ELCLEARPAIRS` |
| 诊断、恢复及目录选择 | `ELPERF`、`ELSTORELEGACY`、`ELRECOVER`、`ELROOT` |
| 预览和颜色重置 | `ELTHUMBRESET`、`ELCOLORRESET` |
| 独立批量编号 | `HLPLBH`、`HLPLBHSET`、`HLPLBHRECOVER` |

宿主只新增 `EmergencyLighting` 命令，不注册与 `ELSTAT`、`CCKK` 等重名的 .NET 包装，避免业务命令再次进入宿主。默认设备 DWG/SLD、设备索引 ELD、系统图块库 DWG、界面 DCL 和版本 marker 均完整保留。

## 加载与错误处理

菜单入口使用 `Session | NoUndoMarker`，在菜单命令结束后的 `Idle` 中向原目标图纸排队投递 LISP。若图纸已经关闭或切换，不向另一张图纸执行。再次点击目标图纸的入口即可启动。

模块绝对路径由宿主 DLL 的实际位置计算，不依赖开发机路径。宿主设置 `*EL:CADToolsRoot*`，只通过模块 `src/load.lsp` 加载。当前图纸同时满足下列条件时复用已有加载结果：

- `*EL:MonitorLoadReady*` 为真。
- `*EL:LiteVersion*` 等于 `lite-v0.1.61`。
- `*EL:Root*` 与当前安装目录相同。
- `C:ELSTAT` 已定义。

需要加载时先清除就绪标记，防止加载异常后误用旧状态。宿主捕获加载错误，未就绪时显示模块错误而不执行统计。已就绪时直接调用原 `C:ELSTAT`，不重载业务模块、不重置当前图纸的统计数据。加载状态保存在各图纸的 LISP 环境中；C# 静态字段只保留尚未投递的目标图纸，不作为模块已加载标记。

入口和版本 marker 缺失时直接显示完整文件路径。其他运行文件缺失由上游入口的完整性检查报告。模块仍遵守 AutoCAD 可信路径设置，不修改 `SECURELOAD`。
