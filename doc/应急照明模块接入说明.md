正常菜单入口使用从完整包 `ELFULL84.lsp` 派生的 `ELFULL84-CADTools.lsp`。适配将目录解析固定到宿主准备的用户目录，并内嵌包内原样的 `src/batch-number.lsp`，保留 `HLPLBH` 系列。test4 额外覆盖首次配电箱拾取反馈、生成受阻提示和面板轻量诊断导出；其余业务模块由原完整入口提供。适配入口为严格 GB2312、无 BOM，SHA-256：`bd617371b7a44af6db98376d8b5867193fed577c8874c910b420ab9db342572b`。原始 ZIP 中仍保留上游独立入口和开发资料。

## 使用与数据

选择“张裕锋工具集 → 15 应急照明”或输入 `EmergencyLighting`。宿主在当前图纸按需准备并加载模块，首次运行完整初始化后打开 `ELSTAT`；同一图纸再次进入时，如果版本、目录和就绪状态一致，则直接使用现有 `ELSTAT`。切图及新图纸分别检查，加载错误时不调用旧统计代码。

宿主按原始 ZIP 和适配入口的固定 SHA-256 校验交付文件，将包内 `src`、`ui`、默认设备资源、模板、`native` 和版本标记共 149 个文件按原字节准备到：

```text
%LOCALAPPDATA%/Emergency-Lighting/CADTools/
```

V1.3.6 在部分远程环境准备 `src/diagnostic-bundle.ps1` 时出现访问拒绝；该脚本内容已完整内嵌在 `ELFULL84-CADTools.lsp` 中，V1.3.7 不再额外写入该外部 `.ps1`。完整 ZIP 保持不变，已部分准备的目录可继续使用。

远程 test3 首次点击配电箱出现 `0xC0000005`，第二次拾取成功，生成操作后面板仍打开并出现延迟崩溃提示。test4 暂时跳过首次拾取的前置高亮重绘，按阶段记录选择和对象读取；这是一项待远程复测的针对性调整，并非已确认原生异常根因。生成条件不满足时会显示原因。

面板内“导出诊断日志”生成轻量摘要，区分运行中与上一轮记录，最近事件最多保留 120 条，不复制完整关联和图纸保存数据。需要完整关联时，关闭面板后在命令行运行 `ELDIAG`；完整导出仍可能因图纸数据较大而耗时。

原先的 `config/` 与 `output/` 继续位于该目录，准备过程不删除或覆盖其资料；用户设备库沿用上游路径与升级规则。若同名运行文件已存在但与 v0.1.84 不同，程序保留原文件并停止，需先备份并排查。安装器不清理这些用户目录。完整包旧 `config` 不自动迁入；使用前建议备份既有配置和图纸。

完整包提供 `ELSTAT`、`ELDEVLIB`、`ELGEN`、`ELDIAG`、`CCKK`、`CCKK1`、`CCKK2` 等命令；`ELCOLD84` 是独立只读 .NET 识别对照原型，并非完整 .NET 识别。该原型加载用户目录中的 DLL 时仍遵守 AutoCAD 的可信路径策略，本工具不修改 `SECURELOAD` 或 `TRUSTEDPATHS`。同一张打开的图纸不建议混用其他完整版和工具集模块，切换前应关闭并重新打开 CAD。
