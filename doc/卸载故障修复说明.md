# V1.3.5 卸载故障修复说明

日期：2026-10-20

状态：修复包已构建，4 项隔离回归通过；真实 AutoCAD 窗口交互待复测

## 现象与依据

用户截图中，点击“关于”窗口的“卸载软件”后，插件先提示卸载程序已启动，随后卸载器提示 `C:\ProgramData\Autodesk\ApplicationPlugins\ZYF.bundle\unins000.dat` 文件已损坏，无法卸载。

Inno Setup 在执行 `InitializeUninstall` 之前读取、校验 `.dat`，因此截图能确认卸载器拒绝了现有记录，不能将记录损坏直接归因于初始化回调。另经代码检查，两个卸载入口均写死标准目录中的 `unins000.exe`，旧初始化回调还会在用户确认前结束字体程序、删除标准目录联接。这些行为一并修复。

参考：[Inno Setup 卸载源码](https://github.com/jrsoftware/issrc/blob/main/Projects/Src/Setup.Uninstall.pas)、[卸载记录追加规则](https://jrsoftware.org/ishelp/topic_appendnotes.htm)。

## 当前安装的修复步骤

1. 保存图纸，关闭所有 AutoCAD 窗口和此前失败的卸载窗口。
2. 以管理员身份运行 [zyf-cad-toolkit-1.3.5-uninstall-fix.exe](../dist/zyf-cad-toolkit-1.3.5-uninstall-fix.exe)。
3. 选择原来的安装根目录，即包含 `ZYF.bundle` 的目录，例如 `D:\ZYFTools`。不要选择 `Contents` 或标准插件目录的联接作为新的安装位置。
4. 完成覆盖安装。修复包使用 `UninstallLogMode=new`，生成新的卸载程序和记录，例如 `unins001.exe` / `unins001.dat`；原有记录保留到卸载阶段。
5. 打开 Windows 设置的“已安装的应用”，找到“张裕锋工具集”，执行卸载。该入口已更新到新卸载程序，避免再次手工启动旧的 `unins000.exe`。

修复包沿用 1.3.5 版本号，仅供本地覆盖修复；原版安装包和网站下载未替换。本次没有操作当前系统中的正式安装，也没有关闭用户的 CAD 或卸载软件。

修复包大小：7,003,032 字节。SHA-256：`00bb80f749e56b018d22ba96019545597346d70ee228f6afac289a1aec1bd41b`。原版 V1.3.5 安装包仍为 7,000,567 字节、SHA-256 `93fe021d99ae7080846d888a40a9b193761cca5430f2078cb1ad5602eb34f204`。

## 修改后的行为

- 两个 CAD 内卸载入口调用同一个服务；解析程序集的真实路径，优先使用匹配当前安装目录的注册记录，不依赖联接或固定 `000` 编号。
- 卸载独立进程以管理员权限启动，关于窗口在启动后关闭，不再叠加“已启动”的提示框；取消 UAC 时保留关于窗口。
- CAD 尚在运行时，独立卸载窗口提示保存、关闭全部 CAD 后“重试”，或取消；静默卸载则无改动退出。实际删除前再次检查。
- 用户确认并且 CAD 关闭后才结束字体辅助程序；卸载末尾通过 `RemoveDirectoryW` 移除目录联接本身，不递归清理其他联接目标或手工部署目录。
- 保持原 `UninstallFilesDir` 与 AppId，普通安装继续追加健康记录；修复包单独启用新记录。应急照明的用户数据仍存放在安装目录之外。

## 验证与复测

Release 编译已通过，0 警告、0 错误。`tools/test_uninstall.py` 将安装目录、目录联接和测试文件限制在工作区 `obj/uninstall-smoke-*`；关闭系统卸载注册，进程检测及结束仅针对专用模拟进程。

4 项隔离回归全部通过：自定义安装目录及联接路径卸载；初始化取消后文件字节和联接保持不变；故意破坏 `.dat` 复现失败、修复安装生成 `unins001` 并成功卸载；专用 CAD 模拟进程运行时无改动退出，进程关闭后才结束字体模拟进程并卸载。测试证据保存在 `Zyf.autoCAD/obj/uninstall-smoke-0vojkbpq`。

48 个 LSP 严格 GB2312、无 BOM 检查通过，全部 154 个 Tools 文件与 Release 输出字节一致。修复包在最终 Release 构建完成后编译，并完成大小和 SHA-256 校验。

隔离测试不等于原生 AutoCAD 窗口验收。真实环境仍需点击“关于 → 卸载软件”，验证可保存图纸、退出全部 CAD 后重试，以及取消和 UAC 取消时的界面行为。
