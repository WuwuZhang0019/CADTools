## 对外更新内容

1. 图号支持电、建、水、暖、结、电装、建装等不同长度的专业前缀，以及不同数字位数，保留前导零。
2. `THDZ` 递增支持大小写和多位进位，例如 `电装施-001 → 电装变-001A`、`Z → AA`、`z → aa`；首次变更默认追加大写 A。
3. 新增 `THDJ` 递减，支持 `AA → Z`、`aa → z`；`A／a` 再递减还原为“施”，已有“施”图号保持原样。
4. 两条命令均可独立启动，加载脚本只注册命令，再执行所选方向。图号专项说明见[图号升级说明](图号文字递增升级说明.md)。
5. 整体保留此前 1.3.7 候选已有的 CAD 运行时安装更新、独立版本目录、应急照明拾取阶段记录、生成提示及轻量诊断改进。有关原生问题尚未完成的验收不能写成已解决。
