# 张裕锋 AutoCAD 工具集（ZYFTools）

日期：2026-10-16

状态：V1.3.3 已发布；应急照明模块已本地集成，尚未发布

ZYFTools 是一个面向 AutoCAD 的 Windows x64 插件工具集，通过 C#、AutoCAD .NET API、AutoLISP/VLX 和独立字体辅助程序，提供常用绘图、图框、图层及文件处理功能。插件加载后会创建“张裕锋工具集”菜单。

- Windows x64

## 安装

### 使用安装器（推荐）

1. 保存图纸并关闭所有 AutoCAD 实例。
2. 以管理员身份运行 [dist/zyf-cad-toolkit-1.2.1.exe](dist/zyf-cad-toolkit-1.2.1.exe)。
3. 按安装向导选择安装目录并完成安装。
4. 重新启动 AutoCAD，在菜单栏中找到“张裕锋工具集”。

安装器默认将文件安装到 `%ProgramFiles%\ZYFTools\ZYF.bundle`，并在 AutoCAD 标准插件目录中创建以下目录联接：

```text
C:\ProgramData\Autodesk\ApplicationPlugins\ZYF.bundle
```

安装或卸载前必须关闭 AutoCAD。字体辅助程序若正在运行，安装器会先将其关闭。

### 手工部署

1. 使用 Release 配置构建项目。
2. 在 `C:\ProgramData\Autodesk\ApplicationPlugins` 下创建 `ZYF.bundle`。
3. 将 `Zyf.autoCAD/PackageContents.xml` 复制到 `ZYF.bundle` 根目录。
4. 将 `Zyf.autoCAD/bin/Release/net47` 中的构建输出完整复制到 `ZYF.bundle/Contents`。
5. 重启 AutoCAD。

最终目录至少应包含：

```text
ZYF.bundle/
├── PackageContents.xml
└── Contents/
    ├── ZYF.autoCAD.dll
    ├── Resource/
    └── Tools/
```

部分命令按 AutoCAD 标准插件路径加载资源，因此手工部署时应使用上述目录，不要只通过 `NETLOAD` 加载 DLL。

## 构建

### 前置条件

- Visual Studio 或支持目标框架的 .NET SDK
- .NET Framework 4.7 Targeting Pack
- NuGet 包还原能力
- 构建安装器时需要 Inno Setup 6

### 构建插件

```powershell
dotnet restore Zyf.sln
dotnet build Zyf.sln -c Release
```

主要输出目录：

```text
Zyf.autoCAD/bin/Release/net47/
```

项目的 `DeployToAutoCAD` 默认为 `false`。如需使用项目内置的构建后部署逻辑，应先确认目标目录和管理员权限；日常开发建议手工复制构建输出，避免覆盖正在使用的插件。

### 构建安装器

安装脚本位于 [installer/ZYFTools.iss](installer/ZYFTools.iss)。编译前需要：

1. 将脚本中的 `ProjectRoot` 改为当前仓库的绝对路径。
2. 确认 `AppVersion` 与项目文件、`PackageContents.xml` 中的版本一致。
3. 先完成 Release 构建，再使用 Inno Setup 编译脚本。

安装包输出到 `dist/`。

## 更新机制

- AutoCAD 启动进入空闲状态后，插件静默检查更新，不在启动阶段强制弹窗。
- 检测到新版本后，仅在用户执行核心业务命令时进行低打扰提醒，每个 CAD 会话最多提醒一次。
- 可在“关于”窗口中查看版本、手动检查更新或跳过指定版本。
- 直接下载安装包时会校验 SHA-256；外部分发链接则由用户下载并自行核对校验值。
- 网络不可用不会阻止绘图命令执行。

更新机制的设计和验收说明见 [doc/更新机制方案.md](doc/更新机制方案.md)。

## 验证建议

仓库提供编码和应急照明交付文件检查脚本；这些离线检查不能代替原生 CAD 验收。发布前至少应在目标 AutoCAD 版本中验证：

1. 插件能够自动加载并创建菜单。
2. 全部业务工具及其辅助配置命令可以正常执行；应急照明还需验证不同图纸首次加载、重复使用、设备库保存及 CCKK 系列。
3. 字体辅助程序不会重复启动，也不会抢占输入焦点。
4. 静默更新、手动更新、版本跳过和弱网容错符合预期。
5. 自定义安装目录、标准插件目录联接、升级和卸载流程正常。
