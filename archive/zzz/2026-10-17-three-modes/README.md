## 当前正式使用版本

仓库根目录下的 `Zyf.autoCAD/Tools/14 缺失字体替换(zzz).lsp` 使用用户提供的 `14 缺失字体替换(zzz) (1).lsp`，保留六个等大按钮、对齐的说明列和自定义字体区域；命令仍为 `ZZZ`。

正式 LSP：20274 字节，SHA-256：`e30326f13af2a2eead86bc62cdc4c6611e622173a562659ddd07682a560e8773`。

三模式版不纳入正式工具构建与菜单加载。正式按钮版没有“源字体 -> 目标字体”的定向替换功能，自定义字体会批量修改可处理的文字样式。

## 归档版离线检查

在仓库根目录运行：

```powershell
python -X utf8 archive/zzz/2026-10-17-three-modes/tools/check_zzz_modes.py
```

这些离线检查不代替原生 AutoCAD 的显示、保存重开及撤销验收。
